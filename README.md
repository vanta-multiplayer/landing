# Vanta Landing Website

Landing page for Vanta Multiplayer.

## Stack

- Astro 5
- Solid.js + TypeScript
- Tailwind CSS v4
- Kobalte UI primitives
- Lucide Solid icons

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site is static by default. Solid is used only for interactive islands such as navigation, particles, scroll progress and FAQ.
